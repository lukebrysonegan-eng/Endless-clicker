# Deep Bore

An endless drilling clicker game in a single HTML file.

Click or hold anywhere to drill, hire rigs, buy one-time Workshop upgrades, and bore through Earth's real layers into rock that never ends. Cap the bore to collect core samples that boost every future run.

## Play

Open `docs/index.html` in any browser. Progress saves in your browser.

## Install it like an app

Deep Bore installs from the web, so it isn't in the App Store. Once installed it opens full-screen from its own icon and plays without internet.

- **iPhone or iPad:** open https://lukebrysonegan-eng.github.io/Endless-clicker/ in Safari, tap the Share button, then **Add to Home Screen**.
- **Android:** open the link in Chrome, tap the ⋮ menu, then **Install app** or **Add to Home screen**.
- **Computer (Chrome or Edge):** open the link and click the install icon at the right end of the address bar.

## Editing the game

`index.html` is the game source. After changing it, run `python3 tools/build.py` to rebuild `docs/`, which is what the website serves.
